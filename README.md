# ZCode Expert

按用户意图智能路由技能并编排多步工作流。

## 能做什么 / What it does
- 规则优先匹配最相关技能
- 为复杂任务推荐执行步骤
- 预置投研、持仓、复盘、文档工作流

## 快速使用 / Quick Start
```bash
python3 expert.py "帮我分析ETF持仓"
```

## 示例输出 / Example Output
```text
持仓诊断 → 机会扫描 → 调仓建议
```

## 技术栈 / Tech
- Python 3.9+，正则、JSON

## 适用场景 / Use Cases
- 技能发现、跨技能任务编排
